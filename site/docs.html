Configuration guideGuia de configuração

Everything in dpomo can be changed in the settings window, or by hand in a plain text file. This page lists every option and shows how to make your own themes and characters.

Tudo no dpomo pode ser mudado na janela de ajustes, ou à mão num arquivo de texto. Esta página lista todas as opções e mostra como criar seus próprios temas e personagens.

Generated from dpomo's source code, so the defaults and lists are always the real ones.

Gerada a partir do código-fonte do dpomo, então os padrões e as listas são sempre os de verdade.

The config fileO arquivo de configuração

All settings live in config.toml. dpomo creates it the first time it opens:

Todos os ajustes ficam no config.toml. O dpomo cria ele na primeira vez que abre:

Windows%APPDATA%\dpomo\config.toml
Linux~/.config/dpomo/config.toml
macOS~/Library/Application Support/dpomo/config.toml
  • Shortcut: in the settings window, Configuration file → Open config.toml (or Open folder).
  • Save the file and dpomo applies it right away, no restart needed.
  • Every key is optional. Delete what you don't care about: missing keys use their default.
  • Made a typo? dpomo shows the line and what's wrong, keeps running with your last good settings, and never overwrites your file until you fix it (or click Replace it with the current settings).
  • Your current session and statistics are in state.toml, in the same folder. dpomo writes that one; you don't need to touch it.
  • Atalho: na janela de ajustes, Arquivo de configuração → Abrir config.toml (ou Abrir pasta).
  • Salve o arquivo e o dpomo aplica na hora, sem reiniciar.
  • Todas as chaves são opcionais. Apague o que não te interessa: o que faltar usa o padrão.
  • Errou alguma coisa? O dpomo mostra a linha e o que está errado, continua com os últimos ajustes válidos e nunca sobrescreve seu arquivo até você corrigir (ou clicar em Substituir pelos ajustes atuais).
  • Sua sessão atual e as estatísticas ficam no state.toml, na mesma pasta. Quem escreve nele é o dpomo; você não precisa mexer.

A small example: longer sessions, a light theme and the capybara.

Um exemplo pequeno: sessões mais longas, um tema claro e a capivara.

[timer]
focus_minutes = 50
short_break_minutes = 10

[appearance]
theme = "Latte"
character = "capybara"

Command lineLinha de comando

If dpomo is already running, these send it the request and exit right away; if not, dpomo opens and does it. Bind them to a global shortcut to control dpomo from any app.

Se o dpomo já estiver aberto, estes mandam o pedido para ele e saem na hora; se não, o dpomo abre e faz. Associe a um atalho global para controlar o dpomo de qualquer app.

dpomo --show
Show the main window (same as opening dpomo again).Mostrar a janela principal (igual a abrir o dpomo de novo).
dpomo --toggle
Start / pause.Iniciar / pausar.
dpomo --skip
Skip to the next phase.Pular para a próxima fase.
dpomo --reset
Restart the current phase.Reiniciar a fase atual.
dpomo --mini
Show / hide the floating timer.Mostrar / esconder o timer flutuante.
dpomo --settings
Open the settings window.Abrir a janela de ajustes.
dpomo --quit
Quit dpomo.Fechar o dpomo.
  • Windows: make a shortcut to %LOCALAPPDATA%\Programs\dpomo\dpomo.exe on the desktop, add --toggle to the end of its Target, and set a Shortcut key in its properties.
  • Linux (GNOME): Settings → Keyboard → Custom Shortcuts, command dpomo --toggle.
  • macOS: in the Shortcuts app, a Run Shell Script action with /Applications/dpomo.app/Contents/MacOS/dpomo --toggle.
  • Windows: crie um atalho para %LOCALAPPDATA%\Programs\dpomo\dpomo.exe na área de trabalho, adicione --toggle no fim do Destino e defina uma Tecla de atalho nas propriedades.
  • Linux (GNOME): Configurações → Teclado → Atalhos personalizados, comando dpomo --toggle.
  • macOS: no app Atalhos, uma ação Executar Script de Shell com /Applications/dpomo.app/Contents/MacOS/dpomo --toggle.

Make a themeCriar um tema

  1. Create a themes folder next to config.toml.
  2. Put a .toml file in it, like the example below (e.g. themes/dracula.toml).
  3. In the settings window, Theme → Reload themes and characters, and pick it. Or write theme = "Its name" in config.toml.
  1. Crie uma pasta themes ao lado do config.toml.
  2. Coloque nela um arquivo .toml como o exemplo abaixo (por exemplo themes/dracula.toml).
  3. Na janela de ajustes, Tema → Recarregar temas e personagens, e escolha. Ou escreva theme = "O nome dele" no config.toml.

Rather pick colors by clicking? Choose Custom in the settings, adjust the colors and click Save as file. A theme is one small file: send it to a friend and they can use it too. Colors are "#rrggbb".

Prefere escolher as cores clicando? Escolha Personalizado nos ajustes, ajuste as cores e clique em Salvar como arquivo. Um tema é um arquivinho: mande para um amigo e ele pode usar também. As cores são "#rrggbb".

Make a characterCriar um personagem

  1. Create characters/<id>/ next to config.toml (e.g. characters/cat/). The folder name is the id you use in character = "cat".
  2. Draw the poses below as SVG files. Only idle.svg is required.
  3. Reload themes and characters in the settings and pick it.
  1. Crie characters/<id>/ ao lado do config.toml (por exemplo characters/gato/). O nome da pasta é o id que você usa em character = "gato".
  2. Desenhe as poses abaixo em arquivos SVG. Só o idle.svg é obrigatório.
  3. Recarregar temas e personagens nos ajustes, e escolha.
idle.svg
Before starting and while paused. Required: a missing pose uses this one.Antes de começar e pausado. Obrigatório: uma pose que faltar usa esta.
