Questions

Is Pomolotl really free?

Yes. It's free and open source (MIT license): no ads, no account, no paid version, no trial.

Does it work on Windows 10 and Windows 11?

Yes. Use the installer (no admin password needed) or the portable .zip. There are also versions for Linux (.deb and .tar.gz) and macOS (Apple Silicon and Intel).

Can I keep the timer visible while I work?

Yes. Turn on the floating timer: a small window that stays on top of other apps, in any corner and at any size. Pomolotl can also hide in the system tray, where its icon shows the progress.

Can I change the 25 and 5 minute times?

Yes. Focus, short break, long break and the number of sessions before the long break are all adjustable (50/10, for example). Breaks and focus can also start by themselves.

Does it work offline?

Yes. Pomolotl doesn't need the internet. The only connection is an optional once-a-day check for new versions, which you can turn off.

Will it slow down my computer?

No. It uses 0% CPU while paused and about 12 MB of memory with the window open (7 MB in the tray).

Can I control it with keyboard shortcuts?

Yes. Space starts and pauses, S skips, R restarts and M shows the floating timer; every key can be changed. For shortcuts that work in any app, bind pomolotl --toggle to a key in your system (how).

Why does Windows show a warning when I install it?

The installer isn't digitally signed yet: certificates cost money and Pomolotl is a free hobby project. Click More info → Run anyway. The source code is public and every release is built from it by GitHub Actions.

What is the Pomodoro technique?

A way to work in short, focused bursts: 25 minutes of focus, a 5-minute break, and a longer break after 4 sessions. It makes it easier to start, to stay focused and to rest before you get tired.

Privacy

Pomolotl has no accounts, no telemetry and no ads. Your settings, statistics and session stay on your computer.

The only network request is the update check: once a day Pomolotl asks GitHub's public API (api.github.com) for the number of the latest version. Nothing about you is sent; GitHub sees a normal web request (see GitHub's privacy statement). It never downloads or installs anything by itself. Turn it off in the settings, with check_updates = false, or in the Windows installer.
