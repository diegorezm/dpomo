Privacy

dpomo has no accounts, no telemetry and no ads. Your settings, statistics and session stay on your computer.

The only network request is the update check: once a day dpomo asks GitHub's public API (api.github.com) for the number of the latest version. Nothing about you is sent; GitHub sees a normal web request (see GitHub's privacy statement). It never downloads or installs anything by itself. Turn it off in the settings, with check_updates = false, or in the Windows installer.

Code signing policy
